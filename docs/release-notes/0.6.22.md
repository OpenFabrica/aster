## 改进

- **Agent 终端新的控制方式**：Claude Code、Codex 等 agent 在 SSH 主机上用的浮动终端，顶部那排按钮换成了底部一个深色控制胶囊。胶囊上写着是哪个 agent、哪台主机、现在在做什么，按住按钮以外的地方可以拖到别处。
- **Agent 运行时不会被误输入打断**：agent 连接或运行命令时，终端四周亮起一圈蓝光，这时终端不接受点击和键盘输入，防止你的输入和 agent 的命令混在一起。滚轮照样能翻看输出。
- **「暂停 agent」改名为「接管」**：点「接管」后蓝光消失，agent 暂停，你可以直接在终端里打字；点「交还 agent」让它继续。「中断」不用先接管。

## 修复

- **打开链接后不再残留下划线和网址提示**：按住 Command 点链接打开后，终端里的链接下划线、手形光标和左下角的网址提示有时会一直留着，还会随着输出不停刷新。现在切到别的窗口或弹出确认框时会自动清掉。
