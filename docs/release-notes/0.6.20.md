## 新功能

- **侧栏主机页**：侧栏新增「主机」页，分为主机、密钥、已知主机三个子页。主机以卡片显示，可以按分组管理，双击卡片直接连接，悬停铅笔或右键打开右侧的编辑面板。从主机页连接的 SSH 会话结束后会回到主机页。「设置 → 主机」只保留 Agent 访问。
- **主机系统信息**：从主机页连接成功后，Aster 在后台采集系统、CPU 核数和内存，显示在卡片副标题里，悬停可看内核、架构和根分区用量。卡片图标随系统变化，Ubuntu 主机显示 Ubuntu 标志。已添加为远程机器的主机会带「远程机器」标注。
- **私钥保险库**：私钥可以导入或生成到钥匙串里保管，原生 SSH 连接直接从保险库取用；可以把仍在用磁盘私钥文件的主机改成保险库密钥。
- **Agent 访问已保存主机**：Agent 可以通过 `aster host exec` 与 `aster mcp` 在你保存的 SSH 主机上执行命令。每次访问都需要你在 Aster 里批准，命令在可见的浮动终端里运行，你可以随时查看和接管。设置页会检测并修复失效的 MCP 登记。
- **主机多标签与 known_hosts 管理**：主机可以打多个标签，便于筛选；已知主机可以在界面里查看和删除。
- **命令片段支持标签**，并可直接粘贴到 Pane。

## 修复

- **注销再登录后，终端里能正常打开浏览器**：本机后台服务会活过注销，旧会话里的终端连不上当前桌面，`open`、剪贴板和 `claude /login` 打不开浏览器。现在 Aster 发现后台服务属于旧登录会话时，会换一个新的服务。
- **原生 SSH 更安全**：原生 SSH Pane 一开始就按敏感会话处理；删除原私钥文件前会核对磁盘上仍是同一把密钥；保险库的钥匙串读写不再占用主线程；发行版忽略调试用的环境变量覆盖。
