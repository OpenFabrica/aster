## 修复

- **受管终端里 Claude Code 输入框不再闪烁**：开了「本机后台保活」的 Pane 里，Claude Code 反复查询终端背景色，每次都让整屏重画，输入框不停闪烁。现在这些查询由后台服务直接回答，不再触发重画。
- **受管终端里 Claude Code 跟随浅色主题**：后台服务以前不回答背景色查询，Claude Code 拿不到颜色，总是按深色主题显示。现在后台服务按 Aster 当前的终端主题回答，切换主题后也会跟着变。远程机器上的受管终端暂时仍按深色显示。
- **更新后自动换掉旧的后台服务**：本机后台服务会活过 Aster 更新，以前更新后仍在运行旧版本，新的修复不生效。现在 Aster 打开时会检查：没有终端在运行就自动换成新版本；有终端在运行，会弹窗说明重启会结束几个终端，由你选「现在重启」或「以后再说」。

  从 0.6.20 及更早版本更新时，后台服务一定是旧版本。如果有受管终端在运行，第一次打开会看到这个提示。选「现在重启」后，在各个 Pane 上点「重新启动 Shell」即可。
