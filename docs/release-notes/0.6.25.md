## 新功能

- **agent 的主机终端停靠在 Pane 底部**：Claude Code、Codex 等 agent 调用远程主机时，终端原来是置顶的浮窗，会挡住别的窗口。现在它默认停靠在调用 agent 的那个 Pane 底部，每台主机一个标签，可以收起，也可以拖动调高度。也能弹出成独立浮窗，再停靠回去；你的选择会被记住。
- **Agent 退出时不再弹「会话已结束」提示**：退出 Claude Code 等 Agent 后，窗口顶部不再弹出带 resume 命令的提示。在同一目录新开终端时，resume 命令仍是补全的首选。

## 修复

- **Command 点击链接先确认再打开**：Claude Code 全屏模式下 Command 点击链接，浏览器会在确认框还没点时就自己打开。现在点击只交给 Aster，确认之后才打开。拖选文字不受影响。
- **TUI 异常退出后提示符不再出现乱码**：Claude Code 等程序被强行结束后，移动鼠标或按修饰键会把 `35;167;42M`、`9;5u` 这类字符打进提示符。现在命令结束后的新提示符会复位这些残留状态。
- **屏幕唤醒后终端画面不再冻结**：屏幕休眠唤醒或窗口换到另一块屏后，终端可能停止刷新，要缩放窗口才更新。现在 Aster 会发现卡住并直接绘制，换屏和唤醒时也会重新绑定屏幕。
- **暗色主题下文件预览看得清**：暗色主题里的源码预览，正文原来是深灰色，几乎看不清。现在按外观使用深色配色，切换外观时也会重新着色。
- **agent 主机终端的遮罩更稳**：
  - 遮罩只在你点「接管」后才撤掉，命令之间不再闪烁，空闲时的按键也不会混进 agent 的终端。
  - 遮罩光晕只在连接中和运行命令时呼吸，空闲时保持静止，更省电。
  - 控制胶囊宽度固定，长命令和长主机名不再挪动按钮。
  - agent 终端在前台时按 ⌘W，只收起这个终端，不再关掉工作区的活动 Pane。
