## 新功能

- **粘贴文件和图片**：从 Finder 复制文件后粘贴，终端里得到转义好的文件路径。剪贴板里只有图片时，Aster 先把它存成临时 PNG 文件，再粘贴这个文件的路径。
- **「粘贴为」菜单更完整**：「粘贴选区」和「转义特殊字符后粘贴」现在在终端里都能用。「括号粘贴」总是按括号粘贴模式发送，不管程序有没有开启这个模式。
- **CLI 能改窗口结构**：新增 `pane split`、`pane close`、`tab new`、`tab close`、`tab focus` 和 `tab rename`。脚本和 Agent 可以直接拆分、关闭 Pane，也可以管理标签页。
- **补全 PATH 里的程序**：装了 Shell 集成后，补全能列出 `PATH` 里真实存在的程序名，包括规格库里没有的程序，比如 `rg`、`mise`。
- **ssh 与 Cargo 的动态候选**：`ssh`、`mosh` 会补全 `~/.ssh/config` 和 `known_hosts` 里的主机名。`cargo` 会补全项目里的 bin、example、feature 和 package。
- **命令找不到时的建议**：如果这个命令是项目 `node_modules/.bin` 里的程序，或是已知的 npm、PyPI、RubyGems 命令，Aster 会建议用 `npx`、`pnpm dlx`、`bunx`、`uvx` 这类工具临时运行它。
- **更多纠错规则**：`git push` 被拒绝时建议先 `pull --rebase`；分支已存在时建议切换过去；`cd` 打错目录名时建议名字最接近的目录；Terraform 没初始化时建议先 `init`；权限不足时建议加 `sudo`。
- **从历史中删除候选**：在候选面板里选中一条历史候选，按 ⇧⌫ 可以把它删掉。
- **跳过含凭据的命令**：「设置」里新增一个开关，默认关闭。打开后，含密码、令牌或私钥的命令不会记进补全历史。

## 改进

- **粘贴前不用再删回车**：粘贴的文本末尾的回车会被自动去掉。粘贴只填进输入行，要执行时自己按 Return。
- **粘贴提醒更准确**：下面几种情况不再提醒多行粘贴：
  - 全屏程序（比如 vim）正在运行；
  - 程序开启了括号粘贴模式，并且「信任括号粘贴」打开；
  - Shell 集成确认有命令正在运行。

  含不可见控制字符的内容仍然每次都要你确认。
- 有多个候选，但第一个明显更常用时，也会显示行内建议。
- 几条历史命令同样可能时，行内建议只显示它们共同的下一个词。
- 没有规格的命令：如果你连续两次都没有传文件参数，Tab 就不再列出文件。下次你再传路径，这个行为会恢复。
- 仓库已迁移到 OpenFabrica 组织，应用内的链接和更新源都已改成新地址。

## 修复

- 修复命令输出末尾没有换行时（比如 `cat` 一个末尾不带换行的文件），行尾多出一个反色 `%` 的问题。
