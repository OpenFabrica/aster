## 新功能

- **终端服务实时交接**：升级 Aster 时，后台服务可交接运行中的受管终端，保留进程、画面和回滚历史。交接不可用时仍可选择稍后处理。
- **远程开发机器**：连接主机后可使用服务器监控和文件面板；界面统一了远程开发机器的名称。
- **文件预览**：在右侧 Files 中单击或用方向键选中文件即可预览，按 Enter 或双击固定；图片默认适应窗口，支持拖动平移和双击切换缩放。
- **CLI 与 MCP**：`aster tab list` 和 `aster pane list` 可列出标签与 Pane；MCP 支持列出标签、Pane，以及调用支持的插件命令。

## 修复

- 修复重启时受管终端过早附加导致的连接中断，并缩短服务交接等待。
- 修复新建受管 Pane 时错误启动本地 Shell，以及前台命令状态识别问题。
- 修复部分提示符和 Codex 状态更新触发全屏重绘，导致目录不更新或画面闪烁的问题。
- 修复终端画面持续更新时可能反复全屏重绘，导致闪烁的问题。
