## 新功能

- **自动补全换成新引擎**：补全规则重新整理，来源包括内置 CLI 规格（711 条）、Shell 别名与 PATH、文件和目录、当前目录的历史命令和 README。Git 分支、npm/pnpm/yarn/bun 脚本、Make、Cargo、SSH 主机等候选在后台只读获取，不执行任何项目脚本。
  - 接受键可选 `Tab`、`Tab + 右方向键`、单独右方向键、`Control + Space` 或关闭，默认 `Tab`。
  - 候选面板可选关闭、自动、Esc 或 Option + Esc，默认 Esc。Tab 不再自动选中首项，先用上下键选，再按 Tab 或 Return。
  - 设置里可以查看补全数据库并立即更新，也可以按类别「清除我的数据」。
  - **注意**：学习数据从空库重新开始，旧数据已备份但不导入。剪贴板建议、失败后的纠错建议、Agent 恢复命令置顶这几项暂时没有接入新引擎。
- **Pane 菜单重做**：点击顶部目录胶囊打开新的圆角菜单，鼠标移上去就展开子菜单，不用再点。
  - Git 菜单直接执行操作：Push/Pull 先确认，Fetch 显示进度并可取消，创建分支、Merge/Rebase 先让你选分支。
  - 「通知与权限」在同一标签的分屏间共享，可分别开关声音、通知、徽标、防休眠和鼠标捕获。
  - 「关于此 Pane」显示 Pane ID、命令、打开时间和设备。
- **文件 Pane 更紧凑好用**：
  - 工具栏变紧凑，窄分屏只显示图标；新增「打开方式」，可在访达中显示、复制路径或用别的应用打开。
  - 源码右键菜单提供剪切、复制、粘贴、撤销、语法选择和「发送到 Chat」。
  - 「发送到 Chat」携带选区和行范围，包含未保存的编辑；可以预填到已有 Agent 或终端，也可以新建 Agent 会话，始终由你确认发送。
  - 本地 `.sh` 文件显示运行按钮，在新终端里执行磁盘上的版本。
  - 自动换行和行号移到「设置 → 编辑器」。源码字体跟随终端字体，图片和文字预览可缩放。

## 修复

- **Codex 的主机终端也能停靠到 Pane**：Codex 调用远程主机时，终端原来总是浮窗，也停靠不回去。现在 Aster 按 Codex 的会话 ID 找到调用它的 Pane。需要先在设置里装好 Codex 的 Agent 集成。
- **没有调用方 Pane 时不再显示无效按钮**：agent 主机终端是独立窗口且找不到调用它的 Pane 时，标题栏不再露出点了没反应的「停靠到 Pane」按钮。
